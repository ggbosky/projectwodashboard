# Project Two CRM — desktopová aplikace

Electron obal, který otevře týmové CRM z GitHub Pages ve vlastním okně. Data, účty i nové verze jsou stejné jako na webu, takže aplikaci není potřeba aktualizovat při každé změně CRM.

```bash
npm install
npm start
```

Sestavení pro Windows (funguje i na Linuxu, bez Wine):

```bash
npm run package:win
```

Výsledek je v `dist/Project Two CRM-win32-x64`; tu složku stačí zabalit do zipu.
