# Project Two — CRM

Interní týmové CRM studia Project Two: dashboard s finančními metrikami, LinkedIn sales pipeline (Kanban / seznam) a ochrana proti duplicitnímu oslovení klientů.

React 18 · Vite · Tailwind CSS · Framer Motion · Lucide

```bash
npm install
npm run dev
```

- Demo data jsou v `src/data.js` (tým, fáze, balíčky, kurzy, klienti).
- Změny se ukládají do `localStorage` prohlížeče — aplikace zatím nemá backend.
- Logo je vektorová komponenta `LogoMark` v `src/components/ui.jsx`; originál je v `public/logo-mark.png`.
